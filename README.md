# PetLife：毛茸茸世界

#### 介绍
一个使用 C++ 构建核心逻辑，Qt/QML 构建界面的跨平台电子宠物养成游戏。世界就是咪咪又汪汪啊。

#### 软件架构
本项目采用 CPP + QML 架构：
C++ 层：负责宠物状态管理、时间流逝逻辑、属性计算。
QML 层：负责渲染宠物形象、绘制 UI 界面、接收用户点击交互。

#### 核心功能（已实现）

1.  宠物基类与派生类：定义了通用的宠物属性（心情、饥饿、精力、健康），已实现具体的萨摩耶品种。
2.  游戏管理器 (GameManager)：核心循环逻辑，管理宠物的领养、状态更新。
3.  信号与槽机制：C++ 逻辑层通过信号通知 QML 界面层更新宠物状态。

#### 使用说明

1.  环境准备：Qt 6.x、CMake 3.16+ 、支持 C++11 的编译器
2.  打开终端，进入项目根目录：
- 创建构建目录并进入
mkdir build
cd build
- 运行 CMake 配置
cmake ..
- 编译项目
make -j4
3.  编译成功后，会在 build目录下生成可执行文件 FurryWonderland。直接运行即可。
